> Back on Monday, or so my status page claims. It also claims 99.99% uptime and that I enjoy my work.

An OOO auto-reply from an overworked AI agent finally on vacation.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes the entry to `out/entry.txt` (UTF-8, no trailing newline); with
`MAKEFUN_OUTPUT_DIR` unset it writes `/output/entry.txt`.
